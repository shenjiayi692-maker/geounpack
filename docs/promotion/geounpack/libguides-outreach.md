# 大学图书馆 GIS 指南（LibGuides）外联清单（2026-11-21 核实）

## 中文摘要：这是什么、你要做什么
- 很多大学图书馆有 “GIS 研究指南” 网页，列出推荐的免费 GIS 软件和工具。被列进去 = 一个长期、高权威的链接，而且老师和学生会真的用（他们常收到 .lpk/.gdb 却没有 ArcGIS）。
- 下面是 **20 个（外加 1 个备选）我逐个打开核实过的指南页面**：加拿大 6 个、美国 10 个、英国 1 个（备选再 1 个）、澳大利亚 3 个。“联系人”一栏里的姓名和邮箱都是**指南页面上公开写着的**；页面上没有具体联系人的，我写了图书馆的通用邮箱或联系页面。
- **你要做的事：**
  1. 用**你自己的邮箱**发（不要用群发工具），**每天最多 5 封**。建议先发表格里标 ★ 的（和我们的工具最相关）。
  2. 每封信的**第一句必须针对那个指南改写**（表格“开头可以这样写”一栏给了提示）。不要把同一封信原样发给所有人。
  3. 发出后在表格最后一栏记日期。**2 周后没回复，只跟进 1 次**（模板在下面），之后不再联系。
  4. 对方说不需要或要求别再联系：礼貌道谢，记下来，永远不再发。
  5. 加拿大反垃圾邮件法（CASL）：给“公开发布的工作邮箱”发与对方工作直接相关、一对一的邮件一般是允许的，但必须写清你是谁、怎么联系你，并提供退出方式。模板最后一句就是退出方式，**不要删**。
- ⚠️ 两点诚实原则：
  - 图书馆很在意隐私和“免费”。如果以后 GeoUnpack 开始收费（计划中的免费额度 + 付费），请**在信里就写清楚**（例如 “free for files up to X”），并且回头告诉已经收录的图书馆。否则以后被发现会被删除，还会伤害信誉。
  - 不要催促、不要说“很多大学都已收录”（除非是真的）。

## 英文邮件模板（第一封）

**Subject:** Suggestion for your GIS guide: opening Esri .lpk/.mpk/.gdb files without ArcGIS

```
Dear [Name / GIS & Data Services team],

[Personalised first line, e.g.: Your "Common GIS File Formats" page is one of the few that mentions Esri layer packages (.lpk/.lpkx).]

I'm Jiayi, an independent developer in Canada. I built GeoUnpack (https://geounpack.com/), a free web tool for students and researchers who receive Esri files but don't have ArcGIS. It opens layer packages (.lpk/.lpkx), map packages (.mpk/.mpkx) and zipped file geodatabases, shows the layers on a map, and exports Shapefile, GeoPackage, GeoJSON, KML/KMZ or CSV.

Two things that may matter for a library guide:
- Files are never uploaded: everything runs in the browser using open-source GDAL and 7-Zip compiled to WebAssembly.
- No account or installation, so it works on lab or loaner machines.
It handles vector data only (no rasters yet) and files up to 150 MB.

If you think it would help your users, it could fit in the [section name] section. And if you'd rather point people to the do-it-yourself route, the free method is: extract the package with 7-Zip and open the .gdb folder in QGIS. I'm happy to send a short step-by-step for that too.

Thank you for maintaining the guide.

Best regards,
Jiayi
Independent developer, [City], Canada
[your email] · https://geounpack.com/

If you'd prefer not to hear from me again, just reply "no thanks" and I won't follow up.
```

### 针对 #2 UNT（先给更正，再提工具）的第一段替换：
```
A small update you may want for the Geodatabase entry on your "Understanding GIS Data and Filetypes" page: it says QGIS can't read a feature class without first exporting it to shapefile. Current QGIS versions (via GDAL's OpenFileGDB driver) open file geodatabases directly: Add Vector Layer > Directory > OpenFileGDB, then select the .gdb folder.
```

## 中文操作说明
1. 每天最多 5 封，用自己的邮箱（Gmail 或你的域名邮箱都可以）一封一封发。
2. 改第一句：打开表格里的页面，看一眼那个栏目的标题和内容，用一句话说明你为什么觉得它适合。
3. 把 `[section name]` 换成表格“建议放的位置”里的栏目名。
4. 记录：在表格最后一栏写“11/24 发 → 12/8 跟进 → 已收录 / 拒绝 / 无回复”。
5. 有人回信问问题（比如隐私、是否开源、是否会收费）：照实回答，可以把邮件内容贴给 Claude 帮你起草。
6. 有人收录了：发一封感谢信，并把那个页面链接记到 `docs/research/` 的记录里（以后收费或改名时需要通知他们）。
