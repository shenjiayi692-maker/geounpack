_2026-11-03 · 审阅通过后再动手_

---

## 0. 总原则（防止跑偏）
1. **只做两件事**：① Premiere 浏览器降级工具；② Esri 转换器的技术验证，验证通过才做 MVP。Ableton 排在第 6 周以后，其他新点子一律记到“待定清单”，**第 4 个月检查之前不碰**。
2. **每个页面都必须是能用的工具**，不批量生成纯文章页。
3. **文件只在浏览器本地处理**，不上传服务器。这是两个产品共同的卖点，也省掉服务器成本和隐私责任。
4. **投入有上限**：开发合计不超过 4 周；现金支出第一年不超过 USD 200（域名、少量工具）。
5. **按数据决策**：每个阶段都有通过或放弃的标准（第 8 节），到点就按标准执行，不靠感觉。

## 2. 品牌、域名与法律
- **两个独立站点**：
  - 站点 A：创意软件的“版本降级和兼容”工具站，先放 Premiere，以后放 Ableton 等。
  - 站点 B：Esri/GIS 文件转换站。
- **商标**：域名和品牌名**不能包含** Adobe、Premiere、Ableton、Esri、ArcGIS 这些商标。页面正文可以用描述性的写法（“用于 Adobe Premiere Pro 工程文件”），页脚写明“与 Adobe / Esri 无关联，商标归各自所有者”。
- **开源许可**：Premiere 的降级逻辑参考 prem-down（MIT 许可）。代码里要保留原作者的版权声明，页面上写致谢。动手前再核对一遍仓库的 LICENSE 文件。
- **免责声明**：“使用前请备份原文件，转换结果请自行检查。”
- **隐私政策**：说明文件只在本地处理，不收集文件内容；只用不带 Cookie 的统计工具。
- 域名候选由你挑（第 9 节），我会先查商标冲突和域名是否可注册。

## 3. 技术方案（两个站共用）
| 组件 | 选型 | 理由 |
|---|---|---|
| 前端 | 静态网站（Astro 或纯 HTML + TypeScript） | 每个工具一个页面，对 SEO 友好，加载快 |
| 文件处理 | 浏览器内 JavaScript / WebAssembly | 不上传、零服务器成本 |
| 托管 | Cloudflare Pages（免费） | 全球 CDN，免费 HTTPS |
| 收款 | **Lemon Squeezy**（首选）或 Stripe | Lemon Squeezy 是“记录商户”，会替你处理全球销售税和增值税；你在加拿大，自己处理各国税务太麻烦 |
| 统计 | Cloudflare Web Analytics + Google Search Console | 免费，不需要 Cookie 弹窗 |
| 代码仓库 | 你的 GitHub 私有仓库 | 我在这个环境里开发，推送到你的仓库 |

## 4. 工作块一：Premiere 浏览器降级工具（第 1–2 周）

### 4.1 产品定义
- **做什么**：拖进 .prproj → 选目标版本（2025 / 2024 / 2023 / 更早）→ 下载降级后的文件。
- **不做什么（第一版）**：不处理 Productions 文件夹、不批量、不做 After Effects。
- **收费**：**免费**。页面上放一个“请我喝杯咖啡”，以及站内其他工具的入口。
- **必须写清楚的提示**：2026 版的新功能（新遮罩、新文字工具等）在旧版里不会生效；先备份。

### 4.2 开发步骤
| 天 | 任务 | 产出 |
|---|---|---|
| 1 | 研究 prem-down 的源码：2026 版删掉了哪些字段、怎么补回去、各版本号对照表 | 技术笔记 |
| 2 | 用 JavaScript 重写核心逻辑（解压 → 改 XML → 重新压缩），写单元测试 | 核心库 |
| 3 | 页面：拖放上传、版本选择、下载、错误提示 | 可用的单页 |
| 4 | **真机测试（需要你）**：你在电脑上用 Premiere 2026 打开降级前的文件、用 2025 打开降级后的文件，确认能打开 | 测试记录 |
| 5 | SEO 页面、隐私和免责页、部署上线、提交 Search Console | 上线 |

### 4.3 测试（关键依赖）
- 我在这个环境里**装不了 Premiere**，所以只能保证“文件结构正确”。**能不能真的打开，必须在你的电脑上验证。**
- 需要你有 Creative Cloud 订阅（可以通过 Creative Cloud 安装旧版本）。如果没有，可以用 7 天试用，或者找一位用 Premiere 的朋友帮忙测试。
- 测试用例：空工程、带多个序列的工程、带特效和字幕的工程、大于 50MB 的工程，每个都从 2026 降到 2025 和 2024 测一遍。

### 4.4 第一批页面（8 个）
1. 首页工具：Premiere Pro 工程降级（通用）
2. Premiere 2026 → 2025
3. Premiere 2026 → 2024
4. Premiere 2026 → 2023 及更早
5. 报错原文页：“This project was saved in a newer version of Adobe Premiere Pro”
6. 怎么在旧版里打开新版工程（方法对比：官方 XML 导出 vs 本工具 vs 桌面版 prem-down）
7. 常见问题：哪些功能降级后会丢
8. 关于 / 隐私 / 免责

## 5. 工作块二：Esri 转换器（第 1 周验证，第 2–4 周 MVP）

### 5.1 技术验证（第 1 周，和 Premiere 并行，我独立完成）
- 收集 Esri 公开的示例文件：.lpk、.lpkx、.mpk、.mpkx、压缩过的 .gdb，包含点、线、面和栅格。
- 先在服务器端用 GDAL 确认每种格式能否读取。
- 再在浏览器里用 gdal3.js 跑同样的测试，记录速度和文件大小的上限（目标：200MB 以内能处理）。
- **通过标准**：.lpk、.mpk、.gdb 里的矢量数据都能读取，并导出 Shapefile、GeoJSON、KML、CSV。.lpkx/.mpkx 和栅格可以放到第二版。
- **不通过**：主要格式读不了，或者浏览器内存撑不住 → 停止，向你汇报。

### 5.2 MVP 产品定义（验证通过才做）
- 拖进文件 → 在地图上预览图层 → 查看属性表 → 选格式导出。
- 输出格式：Shapefile（zip）、GeoJSON、KML、CSV；DXF 放到第二版。
- **免费**：预览，加上导出 1 个图层且不超过 1,000 个要素。
- **付费**（定价待验证）：一次性 USD 7 解锁当前文件的全部导出；或者 USD 19/月不限次数。
- 第二版候选：.lpkx/.mpkx、栅格、DXF、坐标系转换。

### 5.3 第一批页面（15 个）
lpk to shapefile、lpk to kml、lpk to geojson、lpk viewer、open lpk without arcgis、lpkx to shapefile、mpk viewer、mpk to shapefile、layer package to shapefile、gdb to shapefile、gdb to kml、gdb to geojson、gdb to csv / excel、MyGeodata 替代品（不上传文件）、常见问题和隐私页。

## 10. 已知风险与应对
| 风险 | 应对 |
|---|---|
| Adobe 加入官方降级功能 | Premiere 本来就定位为免费引流；网站转向其他软件的降级页 |
| prem-down 或别的免费网站做出更好的网页版 | 不跟它们比，核心收费放在 Esri |
| Esri 的格式有加密或非公开结构 | 第 1 周的技术验证会提前发现 |
| 浏览器处理大文件内存不足 | 设定文件大小上限并清楚提示；必要时提供“分图层处理” |
| 论坛发链接被当成广告 | 先有价值的回答再附链接；每个论坛控制频率 |
| Google 收录慢 | 提交站点地图；先通过论坛和清单获得外链 |
| 被抄 | 无法避免；靠更早占位、页面质量和持续更新 |
